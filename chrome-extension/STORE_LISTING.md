## Permission Justifications

### storage
**Why needed:** To securely store the user's authentication token locally so they remain logged in between browser sessions. Without this permission, users would need to log in every time they open Chrome.

### activeTab
**Why needed:** To detect when the user is on a supported meeting platform (Zoom, Meet, Teams) and determine if coaching should be available. This permission allows us to check the current tab's URL without accessing content on other tabs.

### scripting
**Why needed:** To inject the coaching overlay interface into meeting pages. This is essential for displaying real-time suggestions to the user during their calls.

### tabCapture
**Why needed:** To capture audio from the meeting tab for real-time transcription. This enables AI coaching without requiring a bot to join your call.

### offscreen
**Why needed:** To process audio capture in the background, ensuring smooth performance without interrupting your meeting experience.

### Host Permissions (zoom.us, meet.google.com, teams.microsoft.com)
**Why needed:** The extension only operates on supported video meeting platforms. These restricted host permissions ensure we cannot access any other websites the user visits, protecting their privacy.
