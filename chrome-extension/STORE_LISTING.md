Get real-time AI-powered coaching suggestions directly in your browser while you're on Zoom calls. No more missed opportunities or fumbled objections.

When prospects raise concerns, get instant suggestions for how to address them effectively. Never be caught off guard again.

**📊 Talk Ratio Tracking**
See a live breakdown of how much you're talking vs. your prospect. The best salespeople listen more than they talk.

**💡 Smart Question Prompts**
Get suggested discovery questions to uncover pain points and move deals forward.

**🎯 Closing Cues**
Recognize buying signals and get prompts for when to ask for the close.

## Permission Justifications

### storage
**Why needed:** To securely store the user's authentication token locally so they remain logged in between browser sessions. Without this permission, users would need to log in every time they open Chrome.

### activeTab
**Why needed:** To detect when the user is on a Zoom meeting page and determine if coaching should be available. This permission allows us to check the current tab's URL without accessing content on other tabs.

### scripting
**Why needed:** To inject the coaching overlay interface into Zoom meeting pages. This is essential for displaying real-time suggestions to the user during their calls.

### Host Permissions (zoom.us)
**Why needed:** The extension only operates on Zoom meeting pages. This restricted host permission ensures we cannot access any other websites the user visits, protecting their privacy.
