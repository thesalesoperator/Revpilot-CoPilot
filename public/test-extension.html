🎯 RevPilot Extension Test Page

⚠️ Important: Chrome's tab capture can only record audio that plays through the tab. Browser text-to-speech (TTS) bypasses the tab and goes directly to your speakers, so it won't be captured. Use one of the methods below that actually play audio through this tab.

📋 How to Test

1
Start the Extension
Click the RevPilot extension icon and start a coaching session on this tab
2
Play Audio (use methods below)
Upload a sales call recording OR use the Web Audio synthesizer
3
Watch the Coaching Panel
The extension should transcribe the conversation and provide coaching suggestions

🧪 Debug Information

Open Chrome DevTools (F12) and check the console for these logs:

Expected logs when working:

[RevPilot] Content script loaded on: .../test-extension.html
[RevPilot] Test page detected
[RevPilot BG] Starting coaching session
[RevPilot BG] Got stream ID
[Offscreen] Deepgram WebSocket connected
[Offscreen] Audio streaming started
[Offscreen] Transcript: FINAL "Hello this is..."

If you see NO transcript logs:
- Audio is not being captured (check method used)
- Deepgram connection failed (check API key)
- Offscreen document not created

✅ What to Verify

✓ Extension overlay appears Coaching panel shows on page
✓ "LIVE" indicator shows Session is active
✓ Console shows transcript logs [Offscreen] Transcript: FINAL messages
✓ Script progress updates 1/17 → 2/17, etc.
✓ AI suggestions appear Tips change based on conversation
